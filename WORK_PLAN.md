# План работы

Цель: локально и детерминированно получить `answer.csv` с Recall@50-кандидатами для всех benchmark-запросов, а также доказать корректность формата и отсутствие утечки в offline-проверке.

## DAG и контрольные точки

1. **D0 — контракт входов**
   - Зависимости: нет.
   - Вход: три parquet-файла в `data/`.
   - Результат: `audit` проверяет схемы, строки, пропуски, ID и сохраняет агрегированный JSON без сырых текстов.
   - Checkpoint: команда завершается с кодом 0, если критические ошибки отсутствуют.

2. **D1 — нормализация и разбиение**
   - Зависимости: D0.
   - Результат: единая нормализация текста; SHA-256 fold только от нормализованного `search_query`; строки одной текстовой группы не пересекают train/validation.
   - Checkpoint: unit-тесты воспроизводимости fold и агрегации релевантных `item_id`.

3. **D2 — retrieval-индекс**
   - Зависимости: D1.
   - Результат: word/stem и char TF-IDF по полям, train-only transfer и мягкие category/location priors.
   - Checkpoint: на синтетике релевантное объявление попадает в top-k; равные score разрешаются по `item_id`.

4. **D3 — offline-оценка**
   - Зависимости: D2.
   - Результат: tune на fold 0, один независимый confirm на fold 1, абляции и error slices в JSON.
   - Checkpoint: ни один `search_query` heldout-группы не используется в history/metadata fit; JSON содержит число запросов и Recall@50.

5. **D4 — финальный fit и prediction**
   - Зависимости: D2, выбранные веса D3.
   - Результат: fit на всём train, повторно используемый cache с fingerprint входов и конфигурации, `answer.csv`.
   - Checkpoint: ровно один ответ на каждый benchmark `query_id`, не более 50 уникальных corpus ID.

6. **D5 — независимая валидация**
   - Зависимости: D4.
   - Результат: строгая проверка CSV, регистра/regex ID, состава корпуса, повторов и разделителя.
   - Checkpoint: `validate` завершается с кодом 0; повторный `predict` даёт побайтно тот же файл.

Длинные D3/D4 запускаются после smoke-тестов. Код не содержит ответов для конкретных `query_id`, не обращается к API и не публикует сырые описания объявлений.
